# BlueSidebar — پروژه مود Fabric برای Minecraft Java 1.21.11

این یک **پروژه‌ی کد منبع** است، نه فایل JAR کامپایل‌شده. در این محیط نتوانستم Gradle را با وابستگی‌های واقعی اجرا و کامپایل نهایی را تأیید کنم؛ بنابراین قبل از نصب روی سرور اصلی باید ساخته و روی یک سرور آزمایشی تست شود.

## قابلیت نسخه‌ی اولیه
- مود سمت سرور برای Fabric 1.21.11
- به‌روزرسانی حدوداً هر ثانیه
- نمایش Sidebar با عنوان آبی
- نمایش نام کوتاه بازیکن، نام تیم scoreboard و زمان آمار PLAY_TIME به شکل HH:MM:SS

## محدودیت‌ها
- این نسخه یک Sidebar مشترک برای همه بازیکنان می‌سازد؛ هنوز Sidebar شخصی جداگانه برای هر بازیکن نیست.
- زمان بر اساس آمار PLAY_TIME ذخیره‌شده‌ی Minecraft است و ممکن است شامل زمان بازی پیشین همان پروفایل باشد، نه فقط زمان سپری‌شده در این سرور.
- ممکن است با تغییرات API در 1.21.11 نیاز به اصلاح کد داشته باشد. هیچ ادعایی مبنی بر کامپایل موفق یا تست‌شدن این نسخه وجود ندارد.

## ساخت فایل JAR
1. Java 21 نصب باشد.
2. این ZIP را روی کامپیوتر باز کن.
3. در پوشه‌ی پروژه، ترمینال باز کن و دستور `gradle build` را اجرا کن (Gradle باید نصب باشد).
4. اگر ساخت موفق شد، JAR در `build/libs/` ساخته می‌شود.
5. سرور را خاموش کن و JAR را در پوشه‌ی `mods` سرور آپلود کن. Fabric API سازگار هم باید نصب باشد.
6. اول روی یک نسخه‌ی آزمایشی سرور تست کن و از پوشه‌ی world بکاپ بگیر.

## یادداشت فنی
پروژه بر اساس ساختار معمول Fabric Loom و مستندات Yarn 1.21.11 تنظیم شده است. نسخه‌های وابستگی ممکن است نیاز به تنظیم در `gradle.properties` داشته باشند.
