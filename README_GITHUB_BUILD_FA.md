# راه ساده‌تر ساخت BlueSidebar با GitHub

این پروژه هنوز از نظر کامپایل روی سرور واقعی آزمایش نشده است. GitHub می‌تواند تلاش کند آن را بسازد و اگر خطا باشد گزارشش را نشان می‌دهد.

## مراحل
1. فایل ZIP را در لپ‌تاپ از حالت فشرده خارج کن.
2. وارد https://github.com شو و وارد حساب شو یا حساب بساز.
3. از علامت + بالا، گزینه **New repository** را بزن.
4. نام مخزن را `BlueSidebar` بگذار، گزینه **Public** یا **Private** را انتخاب کن و **Create repository** را بزن.
5. داخل مخزن روی **Add file** و بعد **Upload files** کلیک کن.
6. همه فایل‌ها و پوشه‌های داخل پوشه‌ی استخراج‌شده‌ی `BlueSidebar-Fabric-1.21.11` را انتخاب و بکش داخل صفحه. مهم: خود پوشه‌ی اصلی را یک‌لایه اضافه نکن؛ فایل‌هایی مثل `build.gradle` باید مستقیماً در ریشه‌ی مخزن باشند و پوشه‌ی `.github` هم باید آپلود شود.
7. پایین صفحه **Commit changes** را بزن.
8. بالای مخزن وارد **Actions** شو. باید workflow با نام **Build BlueSidebar** اجرا شود. اگر اجرا نشد، داخل آن **Run workflow** را بزن.
9. اگر اجرا سبز شد، همان صفحه‌ی اجرای موفق را باز کن و پایین بخش **Artifacts** روی `BlueSidebar-JAR` بزن تا ZIP خروجی دانلود شود.
10. داخل ZIP خروجی، فایل `.jar` را بردار و از پنل میزبان سرور در بخش فایل‌ها، آن را داخل پوشه‌ی `mods` آپلود کن. مطمئن شو Fabric API هم در `mods` نصب است، سپس سرور را کامل خاموش و روشن کن.

اگر اجرا قرمز/Failed شد، وارد اجرای قرمز شو و از بالای صفحه یا بخش **Build mod** متن خطا را کپی کن و بفرست. تا وقتی JAR ساخته نشده، فایل را داخل سرور نصب نکن.
